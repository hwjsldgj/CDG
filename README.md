# 🦕 恐龙跑酷游戏（Dino Run）

一个基于 Windows 控制台的恐龙跑酷游戏，支持动态难度、最高分记录、游戏回放、历史记录、热配置加载、完整日志追踪等丰富功能。项目采用模块化设计，代码结构清晰，易于扩展和维护。

## ✨ 功能特性

### 核心玩法
- 🦖 **跳跃跑酷**：空格键跳跃，长按可保持上升（可配置）
- 🧱 **障碍物生成**：障碍物间距随游戏时间动态增长，挑战性递增
- ⚡ **速度系统**：速度随分数线性增长，并每隔固定时间倍增
- 💥 **碰撞检测**：精确的 AABB 碰撞检测，游戏结束即触发

### 进阶功能
- 🏆 **最高分记录**：自动保存最高分及产生时间，游戏内实时显示
- 📜 **历史记录**：记录每局游戏的得分、时间、帧数等信息，支持翻页查看
- ▶️ **回放系统**：录制游戏过程（30fps），支持播放/暂停、速度调节（0.5x~4.0x）、单帧步进
- 🔧 **热配置加载**：修改 `config.ini` 后无需重启，自动生效（物理、键位、菜单等）
- 📊 **完整日志追踪**：记录所有按键、界面切换、函数调用、错误信息，日志文件带时间戳
- 💾 **数据持久化**：最高分、历史记录、回放文件均保存在 `data/` 目录

### 界面与交互
- 🎮 **主菜单**：动态菜单项（可配置），支持数字键和方向键选择
- ⏸️ **暂停菜单**：支持继续、重新开始、返回主菜单
- 📋 **历史记录**：显示统计信息（总记录数、最高分、平均分、最新记录时间），支持翻页
- 📄 **文件详情**：查看单局游戏的详细数据（帧数、时长、帧率、恐龙高度范围、障碍物数量统计）
- 🎞️ **回放列表**：选择任意回放文件播放，回放界面显示进度和速度

## 🛠️ 编译与运行

### 环境要求
- Windows 操作系统（依赖 `windows.h` 和 `winmm.lib`）
- 支持 C++11 的编译器（MinGW-GCC、Visual Studio 等）

### 编译命令（MinGW）
```bash
g++ -std=c++11 -O2 *.cpp -o dino_game.exe -lwinmm
```

### 运行
双击 `dino_game.exe` 或在命令行中执行：
```bash
dino_game.exe
```

## ⚙️ 配置文件说明

`config.ini` 是游戏的核心配置文件，所有参数均可调整。修改后无需重启游戏（热加载生效）。

### 功能开关（`[General]`）
| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `ENABLE_BOOST` | 启用速度倍增 | 1 |
| `ENABLE_LINEAR_SPEED` | 启用线性速度增长 | 1 |
| `ENABLE_HOLD_JUMP` | 启用长按跳跃保持最大速度 | 1 |
| `ENABLE_OBSTACLES` | 启用障碍物生成 | 1 |
| `ENABLE_COLLISION` | 启用碰撞检测 | 1 |
| `ENABLE_SCORING` | 启用计分 | 1 |

### 物理参数（`[Physics]`）
| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `BASE_SPEED` | 基础速度（格/帧） | 0.5 |
| `MAX_SPEED` | 速度上限 | 1.5 |
| `SPEED_PER_SCORE` | 每分速度增量 | 0.0004 |
| `GRAVITY` | 重力加速度 | 0.05 |
| `JUMP_VEL_MAX` | 起跳初速度 | -0.42 |
| `MIN_GAP` / `MAX_GAP` | 障碍物最小/最大间距 | 8 / 40 |

### 键位映射（`[Keys]`）
- `JUMP_KEY`：跳跃键（默认 32 = 空格）
- `PAUSE_KEY`：暂停键（默认 80 = P）
- `RESTART_KEY`：重新开始键（默认 82 = R）
- `CONFIRM_KEY`：确认键（默认 13 = 回车）
- `CANCEL_KEY`：取消键（默认 27 = ESC）
- `NAV_UP_KEY` / `NAV_DOWN_KEY`：上下导航（默认 38 / 40）
- 同时可配置键位显示名称（如 `空格`、`ESC` 等）

### 界面文字（`[Menu]`、`[Pause]`、`[GameOver]` 等）
所有界面标题、提示、菜单项标签均可自定义。菜单项支持动态增删（`item_1=开始游戏|start_game`）。

### UI 配置（`[UI]`）
| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `HISTORY_PAGE_SIZE` | 历史记录每页显示数 | 8 |
| `REPLAY_PAGE_SIZE` | 回放列表每页显示数 | 10 |
| `MENU_START_Y_OFFSET` | 主菜单位置垂直偏移 | -8 |

完整配置请参考项目中的 `config.ini` 模板文件。

## 📜 日志系统

程序自动在 `logs/` 目录生成日志文件，命名格式为 `logs_YYYYMMDD_HHMMSS.mmm.log`。

### 日志级别
- **信息**：记录程序启动、界面切换、按键操作、配置加载等正常行为。
- **警告**：记录回放跳帧、配置解析异常等非致命问题。
- **错误**：记录控制台操作失败、文件读写失败等错误。
- **调试**：记录函数进入/退出、详细状态变化（默认不输出，可调整级别）。

### 崩溃处理
- **异常崩溃**：生成 `logs/crash.log`，记录异常代码、地址和系统时间。
- **信号处理**：捕获 `SIGSEGV`、`SIGABRT` 等信号并记录。
- **`std::exception` 捕获**：记录异常信息。
- **控制台关闭事件**：点击关闭按钮或 Alt+F4 时尝试保存日志。

> **注意**：通过任务管理器强制结束进程无法捕获日志，属于系统级限制。

## 💾 数据持久化

### 最高分
- 文件：`data/highscore.dat`
- 内容：最高分数值 + 时间戳（`time_t`）
- 更新时机：游戏结束时自动保存

### 历史记录
- 存储位置：`data/` 目录下的所有回放文件（`.txt`）即为历史记录
- 每个文件包含：开始时间、得分、每帧数据（时间戳、恐龙 Y 坐标、障碍物 X 坐标列表）
- 程序启动时自动扫描并生成统计信息

### 回放文件
- 录制频率：物理步长（`PHYSICS_DT`）的 2 倍（约 30fps）
- 文件格式：文本文件，便于阅读和调试
- 回放时加载文件，按时间线还原游戏状态

## ▶️ 回放系统

- **录制**：游戏开始时自动录制，结束时保存为 `data/开始时间_得分.txt`
- **回放控制**：
  - 空格：暂停/继续
  - 左/右箭头：减速/加速（0.5x ~ 4.0x）
  - 上/下箭头（暂停时）：单帧前进/后退
- **回放来源**：可从主菜单的“回放”入口直接选择文件，也可从历史记录进入文件详情后回放

## 🧩 开发者接口

项目预留了外部控制接口，便于后续扩展：

- `ExternalSetParam(key, value)`：实时修改配置参数
- `ExternalGetStateJSON()`：返回当前游戏状态（JSON 格式）
- `SaveHistory()` / `LoadHistory()`：历史记录持久化
- `StartRecording()` / `StopRecording()` / `Playback()`：录制与回放控制
