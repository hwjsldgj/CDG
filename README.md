# 小恐龙游戏（Dino Run）

一个基于 Windows 控制台的恐龙跑酷游戏，支持动态难度、配置外置、最高分记录、回放框架等扩展功能。项目采用模块化设计，为后续菜单系统、历史记录、网页开发者工具等预留接口。

---

## 功能特性

### 已实现功能
- **核心玩法**：空格跳跃，长按保持上升，碰撞障碍物即结束。
- **动态难度**：
  - 速度随分数**线性增长**（可配置）。
  - 每 `BOOST_INTERVAL` 秒速度**倍增**（可配置）。
- **可配置参数**：所有物理、界面、开关均通过 `config.ini` 调整，无需重新编译。
- **双缓冲渲染**：流畅无闪烁，支持自定义屏幕尺寸。
- **高精度计时**：独立物理步长（60Hz）与渲染帧率（120Hz），游戏速度稳定。
- **最高分**：自动记录单局最高分，并在游戏结束画面显示。
- **中文界面**：得分、结束画面等均已中文化。

### 计划中功能（框架已预留）
- **菜单系统**：开始、设置、历史记录等。
- **历史记录**：保存每局得分、时间、速度曲线。
- **回放功能**：录制并重放游戏过程。
- **网页开发者工具**：通过 HTTP/WebSocket 实时调整参数，可视化状态。

## 编译与运行

### 环境要求
- Windows 操作系统（依赖 `windows.h` 和 `winmm.lib`）
- 支持 C++11 的编译器（MinGW、Visual Studio 等）

### 编译命令（MinGW）
```bash
g++ -std=c++11 config.cpp game_state.cpp render.cpp physics.cpp input.cpp history.cpp main.cpp -o dino_game.exe -lwinmm
```

### 运行
双击 `dino_game.exe` 或在命令行中运行：
```bash
dino_game.exe
```

程序启动后自动进入游戏（菜单框架预留），按 `空格` 跳跃，长按保持上升。

## 配置文件 `config.ini`

所有参数均可在 `config.ini` 中调整，修改后重启游戏生效。若文件缺失，程序使用内置默认值。

### 功能开关
| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `ENABLE_BOOST` | 启用速度倍增 | 1 |
| `ENABLE_LINEAR_SPEED` | 启用线性速度增长 | 1 |
| `ENABLE_HOLD_JUMP` | 启用长按跳跃加速 | 1 |
| `ENABLE_OBSTACLES` | 启用障碍物生成 | 1 |
| `ENABLE_COLLISION` | 启用碰撞检测 | 1 |
| `ENABLE_SCORING` | 启用计分 | 1 |

### 屏幕与布局
| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `SCREEN_WIDTH` | 窗口宽度（列） | 80 |
| `SCREEN_HEIGHT` | 窗口高度（行） | 25 |
| `GROUND_Y` | 地面所在行 | 10 |
| `DINO_X` | 恐龙固定列 | 5 |
| `PLATFORM_WIDTH` | 障碍物宽度（格） | 1 |

### 物理与速度
| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `BASE_SPEED` | 基础速度（格/帧） | 0.5 |
| `MAX_SPEED` | 速度上限 | 1.5 |
| `SPEED_PER_SCORE` | 每分速度增量 | 0.0004 |
| `GRAVITY` | 重力（每帧速度增量） | 0.05 |
| `JUMP_VEL_MAX` | 起跳初速度（负值向上） | -0.42 |
| `MIN_GAP` | 障碍物最小间距（格） | 8 |
| `MAX_GAP` | 障碍物最大间距（格） | 40 |
| `COLLISION_DIST_THRESHOLD` | 碰撞水平距离阈值 | 1.0 |

### 速度倍增
| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `BOOST_INTERVAL` | 倍增间隔（秒） | 20.0 |
| `BOOST_FACTOR` | 倍增系数 | 1.15 |
| `INITIAL_BOOST_TIME` | 首次触发时间（秒） | 20.0 |

### 帧率与计时
| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `PHYSICS_DT` | 物理步长（秒） | 0.0166667 |
| `TARGET_FPS` | 目标渲染帧率 | 120.0 |
| `SCORE_INTERVAL` | 计分间隔（秒） | 0.1 |

### 跳跃钳位
| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `JUMP_TOP_CLAMP` | 上升减速起始高度 | 4.0 |
| `JUMP_BOTTOM_CLAMP` | 最小高度（防止穿顶） | 2.0 |

### 障碍物生成
| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `GENERATE_THRESHOLD` | 生成新障碍的右端距离阈值 | 10.0 |
| `INITIAL_PLATFORM_OFFSET` | 初始障碍物偏移 | 5.0 |

### 健壮性限制
| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `MAX_PLATFORMS` | 最大障碍物数量 | 200 |

## 操作说明
| 按键 | 功能 |
|------|------|
| `空格` | 跳跃（长按可保持上升） |
| `R` | 游戏结束后重新开始 |
| `ESC` | 退出游戏 |

## 开发者接口（预留）
项目已预留以下接口，便于未来扩展：

- **外部参数修改**：`ExternalSetParam(key, value)` 可实时调整配置。
- **状态获取**：`ExternalGetStateJSON()` 返回当前游戏状态（JSON 格式）。
- **历史记录**：`SaveHistory()` / `LoadHistory()` 用于持久化。
- **回放**：`StartRecording()` / `StopRecording()` / `Playback()` 控制录制与回放。
